# Kintsugi Aurelius audiobook release preparation

This branch adds a reader and catalog link, not a functioning store or a deployed Cloudflare service. The public preview uses the existing site sample. No paid audio URLs or files belong in this public repository.

## Migration
1. In Cloudflare, connect this GitHub repository to a Pages project or Workers static-assets project. Test a preview deployment before changing the live domain kintsugiaurelius.com. For the existing static site use no build command and the repository root as the output directory, or a curated static assets directory excluding development files. Preserve existing domain and mail DNS records. Disable GitHub Pages only after Cloudflare custom-domain HTTPS works and rollback is planned.
2. Obtain the 41 original recordings from the final corrected edition; independently verify audio against the manuscript and the existing manifest (31 sections). Assemble M4B with section markers, continuous MP3, and a ZIP of per-section MP3s. No regeneration is required. Store these files and streamed tracks in a **private** R2 bucket, never a public repository or bucket.
3. Implement actual checkout with a payment provider, verify signed payment webhooks server-side, and record durable entitlements in a database. Use secure session cookies and account authentication. No client-side entitlement flags or checkout redirect alone may authorize media.
4. Implement same-origin GET /api/audiobooks/when-i-was-light. Require an authenticated purchaser; return 401/403 otherwise. For authorized owners return JSON {entitled:true,sections:[{index:0,tracks:["/api/audiobooks/when-i-was-light/media/0-1"]}, ...],downloads:{m4b:"/api/audiobooks/when-i-was-light/download/m4b",mp3:"/api/audiobooks/when-i-was-light/download/mp3",zip:"/api/audiobooks/when-i-was-light/download/zip"}}. Include all 31 sections and 41 tracks; omit unready download formats. Use private/no-store responses. Each media and download endpoint must independently verify the entitlement, serve private R2 objects, support byte ranges for seeking and correct MIME types, and set attachment disposition for downloads. Do not expose the original HeyGen URLs.
5. Add sign-in, My Library, and purchase integration before opening sales. Test purchases, refunds, unauthorized direct links, chapter selection, continuous playback, seek/resume, mobile browsers, and offline downloads. Do not advertise full access until assets and backend are verified.

Current blockers: no connected Cloudflare account or private R2 bucket; permanent source audio bytes and assembled files not yet obtained; payment/authentication provider not established. No DNS, checkout, or production deployment change has been made.
